## 使用建议

- **刷题不是读题**：每道题先自己写，再看「常见错误」小节对照，最后用「追问链」自问自答一遍。
- **复杂度要能推**：面试官问「为什么建堆是 O(n)」「为什么快速选择平均 O(n)」，答结论会被追穿，讲义里给了求和与期望分析。
- **优先修边界**：空数组、单元素、全相同元素、`int` 溢出、链表为空 —— 白板上丢分的九成在这。
- **面试前 3 天**：只看三份东西 —— 本 README 的必刷 20 题、各文件的「通用套路模板」、各文件的「常见误区汇总」。
